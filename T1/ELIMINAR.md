## Pasos para sorting:

- Generar inputs:
    en la carpeta INF221/T1/code/sorting/scripts 
        python3 array_generator.py
    o, en la carpeta INF221/T1/code/sorting
        cd scripts && python3 array_generator.py && cd ..

- Para ejecutar sorting (genera outputs, mediciones, plots y tablas):
    en la carpeta /INF221/T1/code/sorting
       (sin tiempo) make run_all

       (con tiempo) time make run_all
