## Multiplicación de matrices
# Instrucciones para hacer correr matrix_multiplication:

- Generar inputs:
    en la carpeta INF221/T1/code/matrix_multiplication poner en la terminal:
        cd scripts && python3 matrix_generator.py && cd ..

- Para ejecutar matrix_multiplication (genera outputs, mediciones, plots y tablas):
    En este caso hay dos opciones, una que te muestra por pantalla cuanto tiempo se demoró en ejecutar todo y otro que no lo muestra.
    En la carpeta /INF221/T1/code/sorting poner en la terminal:
       (sin tiempo) make run_matrix

       (con tiempo) time make run_matrix

# Nota:
este algoritmo de demora aproximadamente 9 minutos en correr y no muestra por pantalla en que matriz/algoritmo va, si esq se quiere que muestre en que matriz/algoritmo va, solo hay que descomentar una línea que se encuentra al final de ejecutarAlgoritmo(....) en matrix_multiplication.cpp
